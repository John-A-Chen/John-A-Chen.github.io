##

Sheet-metal hub flange

flat pattern, DXF

A flat blank for the hub plate, for laser cutting and bending. Each tab folds up along its bend line so that it sits square to its roller axis. Two identical blanks, one turned over, make one wheel.

Flat pattern

Cut Bend line

Derived dimensions

The DXF has the cut outline and holes on layer CUT and the bend lines on layer BEND, in millimetres. A set of four wheels needs two wheels of each hand.

##

The equations used

reference 
Roller axis point            A(t) = ( d, t sin a, t cos a )            wheel axis is z
Distance from wheel axis     rho(t) = sqrt( d^2 + t^2 sin^2 a )
Nominal wheel radius         R = d + r0

Exact roller profile         k    = t sin^2 a / rho
(touches a cylinder R)       s(t) = t + (R - rho) k                    position along the roller
                             r(t) = (R - rho) sqrt(1 - k^2)            roller radius there
Curvature radius at middle   (d + r0 sin^2 a)^2 / (d sin^2 a)

Wheel angle of the contact   phi(t) = atan( t sin a / d )
Full coverage needs          phi(t_end) = pi / N   so   t_end = d tan(pi/N) / sin a,   length = 2 s(t_end)

Effective radius at angle q  max over rollers and s of   d cos q + s sin a sin q + r(s) sqrt(1 - sin^2 q sin^2 a)

Hub tab                      t_h = L/2 + end clearance + T/2           tab mid-plane along the roller axis
                             bend line offset  y_b = t_h sin a - h / tan a
                             flat length to hole  h / sin a + q (Ri + K T) - 2 (Ri + T/2) tan(q/2),   q = a

Wheel speed                  w R = v_cx + v_cy tan g                   g = +/-45 deg, roller axis on the floor
Front left                   w = ( vx - vy - (lx + ly) wz ) / R
Front right                  w = ( vx + vy + (lx + ly) wz ) / R
Rear left                    w = ( vx + vy - (lx + ly) wz ) / R
Rear right                   w = ( vx - vy + (lx + ly) wz ) / R
